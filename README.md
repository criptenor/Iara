# Iara

Iara é um chatbot inteligente integrado ao WhatsApp, treinado com todos os dados do Colégio Pedro II - Campus Duque de Caxias. Sua principal função é servir como uma eficiente máquina de informação, dispersando a maior quantidade possível de dados na rede e respondendo aos alunos com textos prontos e preparados para serem lidos.

## Tecnologias Utilizadas

- **Python**: Linguagem principal de desenvolvimento.
- **Pandas**: Biblioteca para manipulação e análise de dados.
- **MySQL**: Banco de dados relacional utilizado para armazenar e gerenciar informações.
- **SQLite**: Banco de dados leve e autônomo utilizado para armazenamento local.
- **Selenium**: Ferramenta para automação de testes e navegação em navegadores.
- **ChromeDriver**: Driver para controlar o navegador Google Chrome através do Selenium.

## Funcionalidades

- **Respostas Automatizadas**: Iara responde automaticamente às perguntas dos alunos com informações precisas e bem formatadas.
- **Integração com WhatsApp**: Comunicação direta com os alunos através do WhatsApp.
- **Base de Dados Abrangente**: Treinada com um vasto conjunto de dados do Colégio Pedro II - Campus Duque de Caxias, permitindo respostas detalhadas e relevantes.
